# 🎨 Portafolio UI/UX — Sebastián Cáceres Pinzón

Portafolio profesional de **UI/UX Design** creado para presentar proyectos de diseño de interfaces y experiencia de usuario, mostrando no solo el resultado visual, sino también el proceso de investigación, diseño, prototipado y optimización.

## 🚀 Proyectos

### 🍽️ Mesa — Aplicación móvil para restaurantes

Diseño de una aplicación móvil enfocada en facilitar la búsqueda de restaurantes, consulta de información y reserva de mesas.

**Enfoque:**
- Investigación de usuarios
- Arquitectura de información
- Diseño Mobile First
- UI Design
- Prototipado
- Flujo de reservas
- Diseño centrado en el usuario

**Identidad visual:** rojo, marfil y estética editorial.

---

### 🏨 NOCTE — Plataforma de reservas hoteleras

Landing page y experiencia de reserva para un concepto hotelero premium.

**Enfoque:**
- UX Research
- Landing Page Design
- User Flow
- Diseño de conversión
- Sistema de confianza
- Diseño responsive
- Prototipado de experiencia de reserva

**Identidad visual:** azul oscuro, negro y estética hotelera premium.

---

### 🎮 NOVA // SYSTEMS — Experiencia digital Gaming

Diseño de una plataforma digital orientada a computadores y hardware gaming.

El proyecto explora una experiencia visual inmersiva basada en tecnología, rendimiento y personalización.

**Enfoque:**
- Diseño de interfaces
- UX para productos tecnológicos
- Configurador de hardware
- Diseño de interacción
- Visualización de rendimiento
- Responsive Design
- Microinteracciones

**Identidad visual:** estética gaming, RGB, neon y tecnología.

## 🧠 Proceso UI/UX

Los proyectos siguen una metodología orientada a comprender el problema antes de diseñar la solución.

```text
Investigación
     ↓
Identificación del problema
     ↓
Definición de usuarios
     ↓
Arquitectura de información
     ↓
User Flow
     ↓
Wireframes
     ↓
UI Design
     ↓
Prototipo
     ↓
Validación
     ↓
Iteración
```

## 🎯 Objetivo

El objetivo de este portafolio es mostrar la capacidad para transformar necesidades de usuarios y objetivos de negocio en **experiencias digitales claras, funcionales y visualmente atractivas**.

Cada proyecto utiliza una identidad visual diferente para demostrar capacidad de adaptación a distintos productos, industrias y públicos.

## 🌐 Características

- Diseño responsive
- Diferentes estilos visuales por proyecto
- Casos de estudio UI/UX
- Navegación entre proyectos
- Modo oscuro en la página principal
- Interacciones y animaciones
- Diseño adaptable a dispositivos móviles
- Estructura preparada para GitHub Pages
