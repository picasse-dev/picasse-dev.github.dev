Una vista clara del estado de una planta, sin perderse entre variables.

01. Contexto

En una interfaz de supervisión industrial, el operador necesita entender rápidamente si el proceso está funcionando con normalidad, qué variables se están desviando y qué eventos requieren atención. Esta propuesta explora una jerarquía visual para reunir esa información en una sola vista.

Reto de diseño

Priorizar la información crítica y facilitar la detección de anomalías sin saturar la pantalla con indicadores de igual importancia.

02. Usuarios y necesidades

Operador de planta

Necesita identificar estados, reconocer alarmas y consultar tendencias durante la operación.

Supervisor

Necesita comparar indicadores, reconocer patrones y obtener una visión general del proceso.

03. Decisiones de UX/UI

  • Separar estado general, variables en tiempo real y tendencias.
  • Usar color como señal de estado y no como decoración.
  • Dar prioridad visual a alarmas y valores fuera de rango.
  • Agrupar métricas relacionadas y mantener etiquetas legibles.
  • Diseñar componentes consistentes para facilitar futuras ampliaciones.

04. Proceso propuesto

Descubrir

Entrevistar operadores, revisar alarmas frecuentes y mapear tareas habituales. Esta investigación está pendiente de ejecución.

Definir

Priorizar tareas, organizar la información y crear el flujo de consulta del estado de planta.

Diseñar

Construir wireframes, sistema visual, estados de componentes y una vista responsive para distintos tamaños de pantalla.

Validar

Probar tareas con usuarios representativos y medir el tiempo para localizar alarmas o interpretar tendencias.

05. Resultado y siguientes pasos

El resultado actual es una dirección visual inicial, no una solución validada en planta. El siguiente paso sería construir el prototipo interactivo en Figma, comprobarlo con usuarios y documentar los hallazgos.

Transparencia: proyecto conceptual para demostrar el proceso de diseño. No representa un despliegue industrial real ni incluye resultados de pruebas o métricas verificadas.
